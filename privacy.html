Privacy Policy

PixelTap Uploader (the "App") · Last updated: 7 November 2026

The App is a private automation tool operated by the owner of the YouTube channel PixelTapTV. It is used only to publish the owner's own gameplay videos to the owner's own YouTube channel. It is not offered to the public.

1. Use of YouTube API Services

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies to data handled by Google services used by the App.

2. What data the App accesses

  • YouTube account (with the account owner's permission via Google OAuth): permission to upload videos, set video titles, descriptions, tags, thumbnails and privacy settings, and add videos to playlists on the owner's channel. The App reads the channel name to confirm it is connected to the correct channel.
  • Google Drive: only one folder that the owner has explicitly shared with the App, containing the owner's own video recordings. The App reads new videos from that folder and moves processed files to an archive folder. It has no access to any other files.

The App does not access viewers' data, comments, subscriber lists, analytics, contacts, or any data of other people.

3. How the data is used

Data is used only to process the owner's videos and upload them to the owner's YouTube channel. A few still frames from each video are sent to Google's Gemini model (Google Cloud Vertex AI) to draft the video title, description and tags.

4. Storage and retention

  • The OAuth authorisation token is stored encrypted in Google Cloud Secret Manager in the owner's private Google Cloud project.
  • Video files are processed in temporary storage in Google Cloud and deleted automatically when processing ends. Original recordings stay in the owner's Google Drive.
  • Technical logs (for example, file names, processing times and YouTube video IDs) are kept in Google Cloud Logging according to its standard retention period.

5. Sharing

Data is not sold, rented or shared with third parties, and is not used for advertising. Data is only transmitted to Google services (YouTube, Google Drive, Google Cloud) as needed to perform the functions described above.

6. Cookies

The App has no user interface for visitors and does not use cookies or tracking technologies.

7. Revoking access

Access can be revoked at any time on the Google security settings page. After revocation, the stored token stops working and the App can no longer access YouTube. Stored data can be deleted on request by contacting the email below.
